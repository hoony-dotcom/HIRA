# 🏥 건강보험심사평가원 의료장비 상세 현황 조회 시스템

건강보험심사평가원의 대용량 의료장비 상세 현황 데이터를 효율적으로 필터링, 조회 및 시각화할 수 있는 **Streamlit 기반 웹 애플리케이션**입니다. 인하대병원 의용공학팀에서 의료장비 관리 및 조회를 위해 개발하였습니다.

---

## ✨ 주요 기능

### 1. 자동 최신 데이터 파일 감지 (.xlsb)
* 실행 폴더 내에서 `건강보험심사평가원_의료장비 상세 현황_YYYYMMDD.xlsb` 패턴의 파일을 자동으로 탐색하여 가장 최신 날짜의 데이터를 로드합니다.
* 대용량 엑셀 데이터의 성능 저하를 방지하기 위해 **바이너리 포맷(`.xlsb`)과 `pyxlsb` 엔진**을 적용하여 빠른 로딩을 지원합니다.

### 2. 다단 필터링 시스템 (사이드바)
사이드바 영역을 접이식 메뉴(Expander)로 구성하여 화면 공간을 최적화했으며, 단계별 연동 필터를 제공합니다.
* **요양종별 선택:** 기본값으로 `상급종합병원`이 우선 선택되며, 전체 또는 개별 종별 필터링이 가능합니다.
* **장비 대분류 및 세분류 연동 선택:** 대분류 선택 시 하위 세분류 항목이 동적으로 필터링됩니다.
* **텍스트 실시간 검색:** 요양기관명 또는 장비 모델명 키워드로 빠르게 원하는 장비를 찾을 수 있습니다.

### 3. 정렬 및 데이터 시각화
* **정렬 기능:** 조회 결과를 `요양기관명` 또는 `모델명` 기준으로 오름차순/내림차순 정렬할 수 있습니다. (기본값: 모델명 기준)
* **수량 통계 시각화:** 필터링된 데이터의 장비 수량을 Altair 막대그래프를 통해 **수량 기준 내림차순**으로 직관적으로 시각화합니다.
* **과부하 방지 로직:** 장비 대분류가 '전체'일 경우 데이터가 너무 방대하여 발생하는 렌더링 부하를 막기 위해 안내 문구를 출력합니다.
* **UI 시인성 고정:** 모바일 터치나 화면 모드(다크/라이트) 변경 시에도 그래프 레이아웃과 텍스트 시인성이 깨지지 않도록 고정 테마를 적용했습니다.

### 4. 데이터 내보내기 및 연계 링크
* **CSV 다운로드:** 필터링 및 정렬된 조회 결과를 `UTF-8-SIG` 인코딩(엑셀 호환)으로 즉시 다운로드할 수 있습니다.
* **의용공학팀 연계 앱 바로가기:** 사이드바 내 접이식 메뉴를 통해 관련 사내/유관 시스템 링크로 편리하게 이동할 수 있습니다.
